## The importance of Version Control
From what I have learned so far, version control is essential for any application developer. Being able to track step by step all of the changes made to software is vital to combating human error. With version control, there does not have to be any fear when testing or implimenting new ideas because previous versions will be unaffected. In a way, version control is a developers own digital time machine, allowing them to access whatever past version they need. Lastly, version control can enable safer teamwork and eliminate the need for manual backups that can become complicated to keep track of. Overall, version control will be a huge aspect of this course and I intend to take advantage of it to the best of my abilities.
